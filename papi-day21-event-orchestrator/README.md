# PAPI Event Orchestrator 🎻

A comprehensive event monitoring dashboard that demonstrates all Week 3 PAPI skills: multi-chain event streaming, error handling, performance optimization, type safety, and upgrade compatibility.

## Features ✨

- **Multi-Chain Monitoring**: Track events across Polkadot, Kusama, and testnets simultaneously
- **Real-time Event Stream**: Live event updates with animated visualizations
- **Advanced Filtering**: Filter events by type, severity, and chain
- **Performance Dashboard**: Monitor events/second, memory usage, and latency
- **Error Handling**: Graceful error recovery with user notifications
- **Week 3 Skills Showcase**: Demonstrates all Week 3 learning in one application
