# 🚀 Provider Playground - Day 3 Challenge

## Overview
A TypeScript web application demonstrating both Smoldot (light-client) and WSS (WebSocket) providers for Polkadot, built with PAPI.

## Features
- ✅ Connect using Smoldot light client (browser-based)
- ✅ Connect using WSS provider (WebSocket endpoint)
- ✅ Real-time connection status display
- ✅ Performance comparison between providers
- ✅ Polkadot-branded UI with modern design
- ✅ TypeScript with full type safety
