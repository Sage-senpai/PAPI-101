Typed vs Untyped Queries

Traditional Approach

// Step 1: Construct storage key
const key = api.query.balances
  .account.key(address);

// Step 2: Fetch raw hex
const raw = await api.rpc.state
  .getStorage(key);

// Step 3: Manual decode
const decoded = api.registry
  .createType('AccountData', raw);

// Step 4: Hope it works!
const balance = decoded.free;
// Is it .free? .data.free? 🤷

Problems:

  • ❌ Manual key construction
  • ❌ Raw hex handling
  • ❌ No type safety
  • ❌ Breaks on upgrades
  • ❌ No autocomplete

PAPI Approach

// One line, fully typed!
const account = await dotApi
  .query.Balances.Account(address);

// TypeScript knows everything
const free = account.data.free;
const reserved = account.data.reserved;

// Autocomplete works
// Type safety guaranteed
// Updates with runtime ✨

Benefits:

  • ✅ One-line queries
  • ✅ Auto encode/decode
  • ✅ Full TypeScript
  • ✅ Upgrade resilient
  • ✅ Complete autocomplete
