# PAPI TypeScript Test Suite 🧪

A comprehensive testing suite demonstrating how to test PAPI-powered dApps with full type safety.

## Features
- ✅ Unit tests with Jest + React Testing Library
- ✅ Type-safe mocking of PAPI responses
- ✅ Integration test examples
- ✅ Snapshot testing with PAPI types
- ✅ Test coverage reporting

## Getting Started

### 1. Install Dependencies
```bash
npm init -y
npm install --save-dev typescript @types/node jest ts-jest @testing-library/react @testing-library/jest-dom @testing-library/user-event jest-environment-jsdom
npm install polkadot-api @polkadot-api/descriptors react react-dom
npm install --save-dev @types/react @types/react-dom
