# Blockchain Intelligence Dashboard

Production-grade dashboard fusing PAPI real-time chain data with historical indexer archives for complete account intelligence, trend visualization, anomaly detection, and predictive insights.

## Core Capabilities

1. Live state from PAPI (balances, nonce, events)
2. Historical time-series from indexers
3. Unified fused charts & trend overlays
4. Automatic pattern & anomaly detection
5. Predictive trend lines with confidence
6. Smart real-time alerting
7. Detective investigation interface

```bash
npm install
npm run dev
