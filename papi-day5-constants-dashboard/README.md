# 🚀 Chain Constants Dashboard - Day 5 Challenge

## Overview
A TypeScript dashboard fetching live Polkadot constants via PAPI's TypedApi, showcasing chain-first configs over hardcodes.

## Features
- ✅ Live fetch of 8+ key constants
- ✅ Auto-updates and polling
- ✅ Responsive UI with Polkadot theme
- ✅ Full TypeScript safety
- ✅ Hardcoded vs. live comparisons
- ✅ Config export
- ✅ Fetch logging
