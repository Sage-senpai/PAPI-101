# Batch Transaction Studio

Interactive visual tool for composing, simulating, and exporting optimized batch transactions using PAPI.

## Features

1. Drag-and-drop batch builder
2. Real-time gas estimation & savings display
3. Pre-built templates for common patterns
4. Parameter editing with type safety
5. Batch simulation & execution preview
6. One-click PAPI code generation
7. Atomic vs non-atomic selection
8. Clean, animated UI

## Getting Started

```bash
npm install
npm run dev
