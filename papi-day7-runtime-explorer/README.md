# 🚀 Runtime Explorer - Day 7 Challenge

## Overview
A TypeScript web application that explores Polkadot runtime APIs with beautiful visualizations, real-time metadata display, and type-safe direct runtime calls using PAPI's runtime APIs interface.

## Features
- ✅ Direct calls to runtime APIs (Metadata, Transaction Queue, etc.)
- ✅ Real-time runtime version and metadata display
- ✅ Visualization of runtime architecture
- ✅ Comparison of direct vs indirect API access
- ✅ TypeScript autocomplete for all runtime calls
- ✅ Polkadot-themed responsive design
- ✅ Export runtime information as JSON
