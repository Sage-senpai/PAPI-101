Available Runtime APIs

Metadata API

Provides self-description of the blockchain runtime including version, pallets, and capabilities.

await dotApi.apis.Metadata.metadata()
Returns:
  • specVersion - Runtime specification version
  • specName - Chain specification name
  • pallets - Available runtime modules
  • extrinsic - Transaction format

TaggedTransactionQueue

Direct access to transaction validation and processing logic within the runtime.

await dotApi.apis.TaggedTransactionQueue.method()
Enables:
  • Direct transaction validation
  • Fee calculation at runtime level
  • Transaction priority management

AccountNonceApi

Retrieves account transaction sequence numbers directly from runtime state.

await dotApi.apis.AccountNonceApi.method(account)
Returns:
  • Current nonce for account
  • Direct from runtime (not cached)
  • Guaranteed to be correct

Core APIs

Fundamental blockchain operations exposed directly by the runtime.

await dotApi.apis.Core.method()
Includes:
  • Block execution logic
  • State transition functions
  • Runtime core utilities
