# Chain Constants Explorer dApp

A production-ready React dApp that demonstrates PAPI integration with type-safe blockchain interactions, modern UI patterns, and professional development practices.

## Features

1. Type-Safe Blockchain Integration: Auto-generated TypeScript types from Polkadot runtime.
2. Real-time Data Fetching: Live chain constants with automatic updates.
3. Advanced Filtering: Search by name, category, importance, and chain.
4. Beautiful UI: Modern design with Tailwind CSS and animations.
5. Error Handling: Graceful error states and user feedback.
6. Performance Optimized: Code splitting, lazy loading, and optimized bundles.
7. Production Ready: Follows best practices for React dApp development.
