# Week 2 Recap: Multi-Chain Balance Commander

A comprehensive demonstration of all Week 2 PAPI skills combined into a single, powerful dashboard application.

## 🎯 Features

### **Week 2 Skills Showcase**
- ✅ **Real-time Balance Tracking** using Observables
- ✅ **Cross-chain Operations** (Polkadot + Kusama)
- ✅ **Transaction Simulation** with proper signing flow
- ✅ **Multi-chain Dashboard** with live updates
- ✅ **Developer Console** with real-time logging
- ✅ **Progress Tracking** of Week 2 learning journey

### **Technical Highlights**
- TypeScript-first implementation
- Material-UI with custom theme
- Mock PAPI clients for demonstration
- Real-time console logging
- Responsive design
- Performance optimized

## 🚀 Quick Start

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation

```bash
# Clone/download the project files
cd papi-week2-recap-commander

# Install dependencies
npm install

# Generate PAPI types for both chains
npm run papi

# Start development server
npm run dev
